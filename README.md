# semver-demo

Простой Hello World проект для лабораторной работы по семантическому версионированию.

## Запуск
```bash
python main.py Anna ru
```

## Версионирование
Проект использует [Semantic Versioning 2.0.0](https://semver.org/lang/ru/), формат `MAJOR.MINOR.PATCH`:
- **MAJOR** - несовместимые изменения API;
- **MINOR** - новая функциональность с обратной совместимостью;
- **PATCH** - исправления багов с обратной совместимостью.

Каждая версия отмечена git-тегом `vX.Y.Z` и опубликована в разделе Releases.

## Релизы
| Версия | Тип | Описание |
|--------|-----|----------|
| v1.0.0 | Initial | Hello, World! |
| v1.1.0 | Minor | Приветствие по имени |
| v1.1.1 | Patch | Исправлена обработка пустого имени |
| v1.2.0 | Minor | Поддержка нескольких языков |
| v1.2.1 | Patch | Исправлен неизвестный язык |

Подробные описания: [CHANGELOG.md](CHANGELOG.md) и папка [release-notes](release-notes/).
